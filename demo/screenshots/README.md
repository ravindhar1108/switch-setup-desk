# Screenshots Checklist

Drop your real screenshots from Slack and Switch here:

| Filename | What to capture |
|---|---|
| `01-slack-setup-request.png` | The message you posted in Slack asking to set up a repo. |
| `02-scout-investigation.png` | Scout's report in the Switch Console or Slack thread. |
| `03-setup-execution.png` | Setup creating the `.venv` and starting the install. |
| `04-setup-failure.png` | The error trace in the terminal or logs. |
| `05-repair-diagnosis.png` | Repair identifying the root cause and applying the fix. |
| `06-successful-retry.png` | Setup re-running the command and passing. |
| `07-generated-setup-md.png` | The final `SETUP.md` file created in the workspace. |
