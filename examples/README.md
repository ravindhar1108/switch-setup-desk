# Setup Desk Examples

This directory provides illustrative, reference examples demonstrating how Setup Desk processes a setup request, reports intelligence findings, handles a simulated setup failure, diagnoses the root cause, applies a safe correction, and verifies final execution.

> [!IMPORTANT]
> **Illustrative Reference Material**
> The reports and logs in this directory are structured reference examples created to explain the agent communication contracts and self-healing loop. They are **clearly labeled illustrative examples** and must not be interpreted as actual live terminal execution logs from a physical session.

---

## Scenario Overview: Setting Up Flask

The examples follow a realistic scenario using the popular open-source project [Flask (`pallets/flask`)](https://github.com/pallets/flask) on a developer's workstation:

1. [**Sample Slack Request (`sample-request.md`)**](sample-request.md)
   The initial conversational prompt submitted by a developer via Slack.
2. [**Illustrative Scout Report (`scout-report.md`)**](scout-report.md)
   The pre-setup intelligence gathered by the Scout agent: detecting Python version, build system (`flit_core`), prerequisites, and public GitHub discussion considerations.
3. [**Illustrative Setup Report (`setup-report.md`)**](setup-report.md)
   The execution log showing workspace cloning, virtual environment creation, encountering a hypothetical dependency installation error, and final verification after repair.
4. [**Illustrative Repair Report (`repair-report.md`)**](repair-report.md)
   The diagnostic breakdown generated by Repair when the hypothetical installation fails, illustrating the root-cause diagnosis, safe project-local fix, and handoff back to Setup for a successful retry.
